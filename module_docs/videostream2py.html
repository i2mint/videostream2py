videostream2py

stream2py interface to video.

Read frames from a video file or a camera device as a stream2py source.

The package’s entry point is videostream2py.video.VideoCapture, a stream2py.SourceReader backed by OpenCV’s cv2.VideoCapture:

>>> from videostream2py.video import VideoCapture
>>> with VideoCapture(video_input=0) as cap:
...     timestamp, ret, frame = cap.read()
